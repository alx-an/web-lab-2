# Лабораторная работа № 2. To-Do List

Список задач на HTML, CSS и чистом JavaScript. Интерфейс создаётся через DOM API.

- Добавление, редактирование и удаление задач с датой.
- Отметка выполнения, фильтры по статусу и дате, поиск по названию.
- Сортировка по дате в обоих направлениях.
- Перетаскивание задач мышью в ручном порядке без фильтров и поиска.
- Сохранение задач и ручного порядка в localStorage.

## Запуск

Откройте `index.html` в браузере.

Опубликованная версия — [GitHub Pages](https://alx-an.github.io/web-lab-2/).
